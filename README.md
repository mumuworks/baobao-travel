# 🎒 寶寶旅遊日記

兩人私用旅行手帳 · 北歐旅行收藏冊風格

## 功能
- 旅行紀錄（新增 / 編輯 / 刪除）
- 美食紀錄（含評分 + 誰選的）
- 住宿紀錄（含評分）
- 台灣足跡地圖
- 旅行基金追蹤
- LocalStorage 本機儲存（不需後端）

## 技術
- 純 HTML / CSS / JavaScript，無框架依賴
- LocalStorage 暫存資料
- 未來：Google Sheet（資料）+ Google Drive（照片）+ Apps Script（API）
